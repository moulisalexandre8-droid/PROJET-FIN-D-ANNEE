Voici les différents contrôles dont vous aurez besoin pour jouer :

Fiche d’enquête :
S : descendre dans la liste
W : monter dans la liste
Barre d’espace : cocher / décocher une case

Soupçons / accusations :
Flèche droite / gauche : modifier le choix de l’arme
Flèche haut / bas : modifier le choix du suspect

Soupçon :
Appuyer sur Entrée pour valider le soupçon et voir la carte révélée

Accusation :
Maintenir Entrée pour valider l’accusation et vérifier la solution

Souris / déplacement :
La souris permet de lancer le dé, faire une accusation ou un soupçon
Le déplacement se fait ensuite avec les flèches directionnelles
Vous devez vous déplacer exactement du nombre indiqué par le dé
